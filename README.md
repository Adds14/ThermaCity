# ThermaCity

ThermaCity is a project for extracting and analyzing environmental features like Land Surface Temperature (LST), NDVI, NDBI, and tree canopy using Google Earth Engine (GEE) and Machine Learning.

## Project Structure

- `backend/`: FastAPI backend for serving the data and community reports.
- `db/`: Database initialization scripts.
- `gee/`: Google Earth Engine scripts for feature extraction.
- `ml/`: Machine Learning scripts for training and evaluating models.
